# Accessibility Statement for Bean and Nothingness Website

## Our Commitment

RBOR Games is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone and applying the relevant accessibility standards.

## Conformance Status

The Bean and Nothingness website aims to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. These guidelines explain how to make web content more accessible for people with disabilities.

## Accessibility Features

Our website includes the following accessibility features:

### Navigation
- **Skip to main content link**: Press Tab when the page loads to reveal a skip link that jumps directly to the main content
- **Keyboard navigation**: All interactive elements can be accessed using the Tab key
- **Logical tab order**: Focus moves through the page in a predictable order
- **Visible focus indicators**: Currently focused elements are clearly highlighted

### Content
- **Alternative text**: All images have descriptive alt text for screen readers
- **Semantic HTML**: Proper use of HTML landmarks (header, nav, main, footer)
- **Heading structure**: Logical heading hierarchy for easy navigation
- **Clear language**: Content written in plain, understandable language

### Visual Design
- **Color contrast**: Text and interactive elements meet WCAG AA contrast requirements
- **Responsive design**: Content is accessible on screens from mobile phones to large desktops
- **Resizable text**: Text can be resized up to 200% without loss of functionality
- **No color-only information**: Information is not conveyed by color alone

### Interactive Elements
- **Keyboard accessible**: All buttons, links, and controls work with keyboard only
- **Focus management**: Focus is managed appropriately during interactions
- **Touch targets**: Buttons and links are large enough for easy tapping on mobile (minimum 44x44 pixels)
- **ARIA labels**: Screen reader users receive appropriate announcements

### Forms (When Implemented)
- **Clear labels**: All form fields have associated labels
- **Required field indicators**: Required fields are clearly marked
- **Error messages**: Errors are announced to screen readers and clearly visible
- **Success messages**: Successful submissions are confirmed accessibly
- **Input validation**: Real-time validation helps prevent errors

## How to Use This Website

### With a Keyboard
1. **Tab key**: Move forward through interactive elements
2. **Shift + Tab**: Move backward through interactive elements
3. **Enter key**: Activate links and buttons
4. **Space bar**: Activate buttons and checkboxes
5. **Arrow keys**: Navigate within dropdowns and menus
6. **Escape key**: Close dialogs and menus

### With a Screen Reader

#### Popular Screen Readers
- **Windows**: NVDA (free) or JAWS
- **macOS**: VoiceOver (built-in, activate with Cmd+F5)
- **iOS**: VoiceOver (Settings > Accessibility > VoiceOver)
- **Android**: TalkBack (Settings > Accessibility > TalkBack)

#### Screen Reader Tips
- Press Tab to move through interactive elements
- Use heading navigation to jump between sections
- Listen for landmark announcements (navigation, main content, footer)
- Images will announce their descriptive alt text
- Links and buttons announce their purpose clearly

### On Mobile Devices
- Tap to interact with buttons and links
- Swipe to scroll through content
- Pinch to zoom if needed
- Use device accessibility features (larger text, VoiceOver, TalkBack)
- All touch targets are at least 44x44 pixels for easy tapping

### Adjusting Your Browser

Most browsers allow you to customize your viewing experience:

#### Increase Text Size
- **Chrome/Edge**: Ctrl/Cmd + Plus (+)
- **Firefox**: Ctrl/Cmd + Plus (+)
- **Safari**: Cmd + Plus (+)

#### Enable High Contrast (Windows)
1. Press Left Alt + Left Shift + Print Screen
2. Select "Yes" to enable High Contrast

#### Use Browser Reader Mode
- **Firefox**: F9 or View > Enter Reader View
- **Safari**: Cmd + Shift + R
- **Edge**: F9 or Settings > Reading View

## Known Limitations

We are aware of the following limitations:

1. **Third-party content**: Some embedded content (YouTube videos, social media) may have their own accessibility issues we cannot control
2. **Legacy jQuery**: We are working to update older JavaScript libraries
3. **Color contrast**: Some social media button colors may not meet AAA contrast standards (but do meet AA)

## Feedback and Reporting Issues

We welcome your feedback on the accessibility of the Bean and Nothingness website. Please let us know if you encounter accessibility barriers:

### Contact Information
- **Email**: info@beanandnothingness.com
- **Subject line**: Website Accessibility

### When Reporting Issues, Please Include:
- **Page URL**: The web page where you experienced the issue
- **Description**: What happened and what you expected to happen
- **Browser**: Which browser and version you're using
- **Assistive technology**: If using a screen reader or other tool, which one
- **Steps to reproduce**: How we can experience the same issue

We will respond to accessibility feedback within 5 business days and will work to resolve issues as quickly as possible.
